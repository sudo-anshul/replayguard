A controlled starting point

Observe A.
Then submit B.

Three original messages submit A, one per handler. The runner waits until A’s receipt and correlated post-commit failure are observed for every handler before submitting B.

SQS decides the actual retry schedule. The page shows that recorded schedule without forcing it into the local replay’s four steps.

  1. 01
    A’s receipt commits

    The receiver owns the durable receipt and conditionally creates it.

  2. 02
    The response fails after commit

    The first receive fails before returning success. The receipt survives.

  3. 03
    A’s evidence opens the B gate

    B is a different valid order sharing the same product.

  4. 04
    Observe real redeliveries

    Keep all observed receipts, conflicts and retries. Missing evidence stays incomplete.
