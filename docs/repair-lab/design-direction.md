# Repair bench direction

Primary user: a developer deciding whether a retry repair preserves every valid business order. Primary action: inspect a counterexample, run a trusted Python adapter locally, then import fresh observations.

Retain ReplayGuard's Avenir/Segoe typography, mist background, ink, forest success and rust violation roles. Base text is 18px; controls 16px; outcome numerals 36px. Status always has words and symbols. No external assets, fake metrics, testimonials or new visual brand.

The main composition is an order-by-candidate comparison rather than three decorative summary cards: shared input schedule, candidate columns, one receipt count per business order, then a selected candidate's trace and assertion evidence. The memorable moment is a missing receipt slot for legitimate order B beside a duplicate stack and the correct single receipt.

Narrative: precise product promise → choose a bounded case → compare every order → inspect why a candidate failed → execute/export/import → dated original AWS experiment. Distinguish business outcome, evidence completeness and execution provenance. Labels state that examples are recorded local runs. The browser never claims to execute Python.

Responsive: native case selection and a deliberate horizontal comparison region on very narrow displays, plus a concise selected-candidate inspector. At desktop the comparison owns the page width. On mobile, instructional panels stack and code scrolls locally. No fixed overlay that hides controls.

Motion only responds to case/selection changes; no autoplay pretending a fresh run. Honor reduced motion. Use semantic table headings, visible focus, native details/dialogs, explicit import errors and retained state after a rejected file.

Research basis: the previous rendered ReplayGuard redesign and the competitor public UI inspected in the strategic review. Transfer task clarity and selectable controlled cases; do not copy competitors' compositions. Retain the existing brand to keep this a coherent functional expansion.
